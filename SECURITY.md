# Reporting a security concern

Do not post credentials, database extracts, personal information or exploit
payloads containing private data in public issues. For a concern involving
this showcase, use GitHub's private vulnerability reporting if it is enabled.
If it is unavailable, open an issue requesting a private contact without
including sensitive details.

Only the current portfolio edition is maintained here. This project is a
local demonstration, not an operational service. Do not use its published
reviewer password for a business deployment.
